# Dodge-Survive 🛡️🏃‍♂️

Dodge-Survive is an adrenaline-pumping, fast-paced arcade game where you play as a bold character dodging a relentless swarm of enemies. Survival is the only goal!

## 🚀 Live Demo
**[Check out the game here!](https://YeMinMyat16.github.io/Dodge-Survive/)**


---

## 🎮 How to Play

| Action | Control |
| :--- | :--- |
| **Move** | `W`, `A`, `S`, `D` or `Arrow Keys` |
| **Dash** | `Space` (Temporary speed boost & invulnerability) |
| **Shield** | `Shift` (Deflects the next enemy hit) |
| **Slow-Mo** | `E` (Slows down time for everything except you) |

### Power-Ups ⚡
-   🍏 **Shield**: Grants an extra layer of protection.
-   🟦 **Slow**: Slows down enemies for a duration.
-   🟪 **2x Score**: Doubles your score gain temporarily.
-   🟨 **Magnet**: Pulls power-ups towards you.

---

## ✨ Key Features
-   **Dynamic Difficulty**: The game gets faster and harder the longer you survive!
-   **Custom Assets**: High-quality character icons for both the player and diverse enemy types.
-   **Ability System**: Master the Dash, Shield, and Slow-Mo to beat your high score.
-   **Particle Effects**: Satisfying visual feedback for movements, collisions, and power-ups.
-   **Smooth UI**: Modern, responsive design with glassmorphism and crisp typography.

## 🛠️ Local Development

### Prerequisites
-   [Node.js](https://nodejs.org/) (v18 or higher)
-   npm

### Setup
1.  **Clone the repository**:
    ```bash
    git clone https://github.com/YeMinMyat16/Dodge-Survive.git
    cd Dodge-Survive
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```
